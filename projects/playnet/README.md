# Playnet

An economic planner for groups whose members already trust each other: people say what they have and what they need, and a convex optimisation over ValueFlows data finds the allocation of labour that meets every need with the least work. Written in Guile Scheme on Spritely Goblins, with KERI identities, a gateway as trust root, and mesh networking over Reticulum. Code on Radicle. People: Ruzgar Imski.
